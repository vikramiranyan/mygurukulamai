# Gurukulam AI UI/UX Direction

The approved visual direction is a dedicated, image-rich Gurukulam AI login page followed by a polished parent dashboard. The reference project is a benchmark only; Gurukulam AI must exceed it.

## Login
- Separate route/page from the authenticated dashboard.
- Rich Gurukulam-inspired educational imagery and child-friendly Indian visual storytelling.
- Prominent Google sign-in CTA.
- Clear privacy/security reassurance.
- Fast, uncluttered first impression.

## Dashboard
- Parent-focused sidebar/navigation.
- Child selector and profile management.
- Progress/learning summary cards.
- Continue learning section.
- AI teacher panel for Vikram/Raji.
- Subject cards and progress.
- Recent activity and learning streak.
- Responsive mobile layout.

## Product rules
- Preserve Google authentication.
- Preserve teacher mapping: Vikram for English, Maths, Computer; Raji for other subjects.
- Do not expose authenticated dashboard controls before successful sign-in.
- Prioritize accessibility, responsive behavior, performance and visual consistency.
