# Gurukulam AI UI/UX Direction

This is the canonical UI/UX acceptance standard for the Gurukulam AI product.

## Login
- Dedicated standalone Gurukulam AI login screen.
- Child-friendly Indian educational visual language.
- Prominent Google sign-in CTA.
- Clear parent/security reassurance.
- Fast, uncluttered first impression.

## Parent dashboard
- Authenticated-only dashboard.
- Parent-focused navigation.
- Child selector and profile management.
- Progress and learning summary cards.
- Continue-learning section.
- AI teacher panel.
- Subject cards and progress.
- Recent activity and learning streak.
- Responsive mobile layout.

## Product rules
- Preserve Google authentication.
- Preserve teacher mapping: Vikram for English, Maths and Computer; Raji for all other subjects.
- Never expose authenticated dashboard controls before successful sign-in.
- Prioritize accessibility, responsive behaviour, performance and visual consistency.
- The reference is a quality benchmark only; Gurukulam AI must meet or exceed it.
